# Day 6 发布元数据

## 发布文案

```
今天昆山下大雨，我蹲阳台抽了一下午烟。
村里老周给我发了条语音："娃，回家过年吧。"
苏北话里的"娃"字，没人这么喊我十年了。
我抢了张K8421的硬卧。

#真实生活 #打工人 #思乡 #苏北 #江苏盐城 #在外打工的我 #隐界 #成年人也哭
```

**字数**：80 字（含标签）
**核心钩子**：「苏北话里的'娃'字，没人这么喊我十年了」 — 引出"为什么是 AI 在喊"

---

## 标签策略

| 标签 | 池子大小 | 快手定位 |
|------|---------|---------|
| `#真实生活` | 极大 | 入门级流量入口 |
| `#打工人` | 极大 | 精准人群 |
| `#思乡` | 中 | D6 的核心情绪标签 |
| `#苏北` | 小但精准 | LBS + 方言共鸣（江苏盐城/淮安/连云港地区) |
| `#江苏盐城` | 小但精准 | LBS 推荐（盐城本地用户被推） |
| `#在外打工的我` | 大 | 异乡情绪 |
| `#隐界` | 小（自家词） | 品牌词沉淀 |
| `#成年人也哭` | 中（快手特色） | 男性情绪共鸣 |

**标签数量**：8 个

**核心策略变化（与 D1 比）**：

- 加了 `#思乡` 和 `#苏北`——这是 D6 独有
- 加了 `#成年人也哭`——这是 D6 的情感锚点
- 砍掉了 `#夜班` 和 `#凌晨碎碎念`（D6 不是夜班场景）

## 评论区第一条（小号 A 置顶）

```
苏北人狠狠破防了，老周这一声"娃"我也跟着哭
```

**目的**：
- 用"苏北人"自称引导**地域共鸣**评论
- "破防"是快手中年男情绪共鸣高频词
- 不出现"AI"或"隐界"（前 30 分钟保持悬念）

---

## 评论区第二条（小号 B，T+15 min · 蹭热度）

```
求求老周这个角色让我也加一个，我也想被喊"娃"
```

**目的**：制造"想要这个 AI"的诉求，为后面引导"什么 APP"铺垫。

---

## 评论区第三条（小号 C，T+30 min · 回复真实评论）

针对**第一个真实问"什么软件"或"老周怎么联系"的评论**回复：

```
是隐界APP，自己建的角色，AI能学方言。我去年装的
```

**关键**：
- 用"自己建的角色"引导"原来还能自己建"
- "AI 能学方言"补一刀技术差异化
- "去年装的"装真实用户
