# 视觉规范（快手 7 条共享）

> 与抖音版 `00-visual-style.md` 大方向一致；本文件只覆盖**差异点**和**快手专属约定**。

---

## 1. 画面规格

| 项 | 值 |
|---|---|
| 分辨率 | **1080×1920** 竖屏 9:16 |
| 帧率 | **30 fps** |
| 编码 | H.264 baseline + AAC 192kbps |
| 安全区 | 上 200px、下 **320px**（快手底部 UI 比抖音少一层，缩到 320） |
| 主轴留白 | 左右各留 60px 边距 |

## 3. 字幕样式（黄金字幕模板 · 快手版）

```
字体：思源黑体 Bold（SourceHanSansSC-Bold）
字号：72px（比抖音的 70 大 2px，老花眼/小屏幕友好）
颜色：#FFFFFF
描边：3px 实心黑色（比抖音的 2px 粗 1px）
阴影：x=2 y=4 blur=8 黑色 30%
行距：1.3
最大宽度：单行 14 中文字（超过强制换行）
位置：屏幕中心偏下，Y 中心 = 1300（比抖音的 1200 低 100px，避开快手顶部弹幕）
出场：fade-in 100ms / 硬切均可
退场：fade-out 200ms，下一句进来前留 80ms 空白
```

**强调字（特殊台词）**：

- 字号放大到 88px
- 颜色变为 `#f97316`
- 加上 1 帧抖动（位移 ±4px，仅 1 帧）

**严禁**（快手语境下会被打"低质"标）：

- 任何"打字机效果"逐字蹦字
- 描边超过 4px（会糊）
- 渐变色（不要彩虹字）
- 艺术字花体（不要金粉字）
- "动感震动字"

## 4. 转场

**默认转场 = 硬切**。这一批 7 条视频里**转场使用次数硬上限**：

| 转场 | 允许使用次数 | 何时用 |
|------|------------|-------|
| 硬切 | 不限 | 默认转场 |
| 0.3s 黑场 | 每条 ≤ 1 次 | 段落结束、字幕浮现前（D7 反转必用 1 次） |
| 0.2s 闪白 | 每条 ≤ 1 次 | 仅 D7 揭示「这些是你写的」时 |
| Cross dissolve（淡化）| 禁用 | — |
| 滑动/缩放/旋转转场 | 禁用 | — |

## 5. 屏幕录制画面"包装"

由于本批视频大量是 APP 录屏 + 实拍空镜混剪，**APP 录屏画面的包装是视觉差异化关键**：

### 5.1 录屏画面占位

```
┌─────────────────────────────┐
│  顶部 200px（快手 UI 安全区） │
├─────────────────────────────┤
│                             │
│   ① APP 录屏画面             │  ← 高度约 1100-1200px
│   （保留原比例，最大宽 960px）  │
│                             │
├─────────────────────────────┤
│  字幕区 280px                │  ← Y 1300-1580
├─────────────────────────────┤
│  底部 320px（快手 UI 安全区） │
└─────────────────────────────┘
```

### 5.2 录屏画面边框

- 录屏画面**加 12px 圆角**
- 录屏画面**外加 2px 描边**，颜色 `#262626`
- 录屏画面**下方加 8px 阴影**：`box-shadow: 0 8px 32px rgba(0,0,0,0.4)`

### 5.3 录屏画面背景

录屏画面下方/周围的背景采用**模糊扩展**：取录屏画面当前帧 → 放大 1.5x → 高斯模糊 60px → 作为背景填满 1080×1920。

## 6. 字幕进入节奏

字幕**必须先于或同时于配音**出现，不能晚于配音。

- 配音说出关键句之前 200ms 字幕就位
- 配音结束后字幕停留至少 800ms 再消失（让下沉用户看完）

## 7. BGM 处理（最大差异化）

### 7.1 总原则

- **禁用**：钢琴、Lo-fi、电子轻音乐、抖音治愈系（这些都太"端着"）
- **优选**：环境音 + 民谣人声 + 偶尔笛子/口琴
- **音量**：人声 0dB / BGM -22 至 -18dB / D6 情感顶点处 BGM -18dB
- **片尾**：BGM 在最后 1 秒切断（戛然而止比淡出更有力）

### 7.2 按场景选曲

| Day | BGM 方向 | 具体推荐（顺序按优先级） | 音量 |
|---|---|---|---|
| D1 | 早餐铺环境音 + 一段口琴 | 1) Pixabay「Morning Folk Acoustic」 2) Free Music Archive 口琴民谣 3) ccmixter 自制口琴 | -20dB |
| D2 | 工厂白噪音 + 蝉鸣 | 录制空调外机声 + 真实蝉鸣（自录或 freesound.org） | -24dB（让消息提示音突出） |
| D3 | 一段半哼半唱的男声民谣 | 1) Pixabay「Acoustic Father Song」 2) Bensound「Hometown」前奏 8 秒 | -22dB |
| D4 | 群聊吵架场景，无 BGM | 仅消息提示音 + 房间空场音（电风扇、远处广场舞） | — |
| D5 | 校园下课铃远景 + 轻吉他 | 1) Pixabay「Schoolyard Bell」 2) Pixabay「Hometown Guitar」 | -22dB |
| D6 | 雨声 + 一段笛子 | 1) freesound.org 真实雨声 2) Pixabay「Bamboo Flute Lonely」 | -18dB |
| D7 | 极简，全程仅环境音，结尾留 3 秒静默 | — | — |

### 7.3 版权红线（必须遵守）

- **所有第三方曲目仅截取前奏 6-8 秒做背景音垫层**，确保不构成完整使用
- 发布前 Manus 必须用 ACRCloud（acrcloud.com）或类似工具复核每条音轨
- 如检出版权 → 立即换成 Pixabay/ccmixter/freesound 的 CC0 同风格替代曲
- **永不使用**：流行歌完整段落、影视 OST 原版、抖音/快手热曲（除非平台标注"可商用"）
- 安全备胎曲库：Pixabay Music、Bensound、ccmixter、Free Music Archive

## 8. 旁白结构（强制三段式）

每段旁白必须按 **「具体动作 + 一个细节 + ≤12 字心里话」** 结构：

> 范例（D1）：
> "我把电动车锁好（**动作**）。豆浆袋子上还冒着热气（**细节**）。今天这趟班，没白上（**心里话，10 字**）。"

**配音标准**：

- 性别：男
- 年龄：35 岁左右
- 口音：苏北/江苏口音底色（**不要普通话播音腔**）
- 语速：220 字/分钟（比抖音的 250 慢 30 字，下沉用户更习惯慢节奏）
- 情感：慵懒疲惫但不丧；偶尔有一点自嘲式的笑

**禁用**：

- "嗯""啊""哒""呐"等口癖
- 假装哽咽（情绪到位时只留气音 ≤1 秒）
- 京腔、东北腔、台湾腔（与人物地理身份不符）

## 9. 镜头节奏（关键差异化）

**每 15 秒必须有一个"生活物件特写"** —— 这是快手生活流的"硬通货"：

| Day | 必备生活物件特写 |
|---|---|
| D1 | 豆浆袋（冒热气）+ 电动车钥匙 + 早餐铺塑料袋上的油渍 |
| D2 | 安全帽（汗渍）+ 烟盒（皱）+ 厂区铁皮门 |
| D3 | 泡面盖子（半开）+ 手机屏幕（油渍指纹）+ 拖鞋 |
| D4 | 床单（褶皱）+ 手机充电线（缠绕）+ 矿泉水瓶 |
| D5 | 儿子的奖状（贴墙）+ 烤红薯（焦皮）+ 出租屋钥匙 |
| D6 | 阳台烟头（被雨打湿）+ 雨伞（破洞）+ 苏北方言短信截图 |
| D7 | 手机屏幕（手抖特写）+ 角色编辑页（关键字段高亮）+ 喝水的玻璃杯（普通） |

特写时长 1-2 秒；构图遵循"占画面 60-70%、背景虚化"。

## 10. 片头片尾

### 片头：0 帧
**没有片头**。第一帧就是钩子画面（生活物件特写）。

### 片尾：最后 1.5-2 秒
- 屏幕渐暗（0.3 秒 fade-to-black）
- 中央显示「隐界」logo（150×150px，居中，Y=900）
- logo 下方一行小字：「一个属于你的 AI 虚拟世界」（思源黑体 Regular，36px，白色）
- 1.5 秒后整个画面 fade-out 到全黑

**不要**：

- "感谢观看"
- "我是 XXX"
- "求关注"
- "下期再见"
- "下集预告"（D6 → D7 的预告靠 publish-meta 的小号矩阵处理，不在视频里）

## 11. 快手 UI 安全区可视化

录屏 + 合成时，要确保画面里以下区域不放关键文字：

```
顶部 0-200px       → 快手状态栏 + 顶部下拉菜单 + 顶部弹幕区
底部 0-320px       → 快手底部 tab + 评论按钮 + 关注按钮
右侧 0-160px       → 右侧操作栏（点赞/评论/分享/收藏）
左下 0-200×0-340  → 文案区 + 话题标签
```

字幕和录屏画面都必须避开上述区域。

## 12. 文件命名规范（产出时）

```
output/
├── day-1/
│   ├── d1_video.mp4         主视频
│   ├── d1_cover.jpg         封面（810×1080，3:4）
│   ├── d1_publish.txt       发布文案
│   └── d1_pinned.txt        评论区第一条（小号置顶）
├── day-2/
│   └── ...
```

成片必须导出 1080×1920 H.264，码率 ≥ 8 Mbps（快手画质门槛比抖音略低，但仍建议 8M+）。
