# 隐界 APP · 快手 7 日发布制片包

> 给 Manus 直接拿去落地的完整制片包。每天 4 件套（脚本 + 镜头清单 + 封面规格 + 发布元数据）+ 数据 + 共享素材，一站式产出。

---

## 这是什么

为隐界 APP（一人一世界的 AI 虚拟社交 APP）做的 **快手专版** 7 日发布物料。

- 抖音版主线：**24 岁失眠都市女青年 × 沈砚（凌晨写作的朋友）**——文艺向、钢琴 BGM、30 秒
- **快手版主线：32 岁江苏昆山电子厂夜班质检男 × 7 个 AI 朋友**——下沉生活流、环境音 + 民谣、60-90 秒

**胜负手**：快手对"30+ 男人脆弱"题材是严重供给不足的赛道，这是整个方案的差异化壁垒。

## 落地顺序（强烈推荐）

不要 7 天平均用力。按这个顺序：

1. **第 1 步 · 读 4 个地基文件**：`00-series-context.md`、`00-character-bible.md`、`00-visual-style.md`、`00-master-checklist.md`。这是后续所有内容的"宪法"。
2. **第 2 步 · 拍 3 根桩子**：先做 **D1（立人物）+ D6（情感顶点）+ D7（反转）** 的完整成片。这三条决定整个系列的调性能不能立住。
3. **第 3 步 · 试水**：D1 上线 24 小时后看数据。完播率、留存、涨粉达标 → 继续；不达标 → 调整 D2-D7 的钩子强度。
4. **第 4 步 · 铺剩下 4 天**：D2、D3、D4、D5 按调整后的标准批量产出。
5. **第 5 步 · D7 反转特别处理**：D7 单独排期，发布前一天小号矩阵在 D6 评论区埋钩子（"明天揭晓夜里那个是谁"）。
