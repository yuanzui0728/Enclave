# Manus 制片清单

> 这是一份"按顺序勾"的总清单。所有 7 条视频从头到尾的工作项，按这个顺序做不会漏。

---

## 阶段 0：环境准备（1-2 天）

- [ ] 读完所有 7 个 `00-*.md` 地基文件
- [ ] 通读 7 个 day-N 目录（先理解再开工）
- [ ] 准备配音演员（1 位男声，35 岁苏北口音底色，能反复录）
- [ ] 准备 APP 录屏环境（建一个测试 world，按 character-bible 配置 7 个角色）
- [ ] 准备实拍/AI 生成环境素材（12 张环境照，清单见 `00-file-index.md`）
- [ ] 注册 ACRCloud 账号（用于 BGM 版权复核）
- [ ] 准备小号矩阵：至少 3 个快手小号（A/B/C），头像简介都设置好

## 阶段 1：素材生产（2-3 天）

### 1.1 角色头像

7 个 SVG 已在 `shared-assets/avatars/`，可直接用。如要在 APP 录屏里替换为更精细的角色立绘，参考 `character-bible.md` 的人设描述生成。

### 1.2 环境照片（12 张）

按 `00-file-index.md` 的清单生成。建议优先级：

- **必须实拍**：morning-soup-stand.jpg（早餐铺豆浆机的真实质感 AI 难还原）
- **必须实拍**：cigarette-pack-crumpled.jpg（皱巴巴的红梅烟盒）
- **AI 生成可接受**：factory-night-exterior.jpg、chenmag-room-day.jpg
- **必须 + 后期处理**：mobile-handheld-blurred.jpg（手抖效果可拍 + 加抖动滤镜）

AI 生成时统一 prompt 模板：

```
[场景描述]，写实摄影风格，纪实质感，不要任何"工业风格"或"治愈系滤镜"，
2026 年江苏中小城市真实生活感，6500K 色温，35mm 焦段
```

### 1.3 聊天数据准备

每个 day-N/data/ 下的 chat.md 和 data.json 已经写好。Manus 的工作是：

- 把 chat.md 内容**严格复刻到测试 world 的对应对话里**（一字不差）
- 录屏时**保留时间戳**（不要假装这是当天发的）
- data.json 给前端工程化渲染用（如果用 HTML+CSS 做长截图）

### 1.4 BGM 准备

按 `00-visual-style.md` 第 7.2 节的清单选 7 首。每首：

- 截取前奏 6-8 秒
- 用 Audacity 做淡入淡出 + 音量归一化到 -22dB
- ACRCloud 复核，过了就标记 ✅，没过就换备胎

## 阶段 3：D1 试水（24 小时观察）

- [ ] D1 按计划发布
- [ ] T+10/20/30 分钟、T+1/2 小时按 `day-1/publish-meta.md` 的 SOP 推进
- [ ] T+24 小时复盘：

| 指标 | 通过 | 触发调整 |
|---|---|---|
| 完播率 | ≥ 30% | < 30% → 检查前 5 秒钩子 |
| 5 秒留存 | ≥ 55% | < 55% → 检查首镜物件特写 |
| 24h 播放 | ≥ 8k | < 5k → 检查标签策略 |
| 24h 涨粉 | ≥ 80 | < 50 → 检查主页简介 |

调整动作：

- 钩子不行 → D2 改用更具体的物件特写（建议直接用安全帽特写 + "诶？凌晨 3 点厂里咋还有人发消息"）
- 留存不行 → D2 把第一句旁白移后 2 秒，先放纯环境音
- 标签不行 → D2 把 #真实生活 提到第一位

## 不要做的事（Manus 警示）

❌ 不要用 AI 一键生成封面（细节没法把控，下沉用户对"AI 风"特别敏感）
❌ 不要用任何"动感震动字"特效（快手会判断为农村号风格）
❌ 不要在录屏里露出测试 world 的端口号、URL（隐私 + 不专业）
❌ 不要在视频里出现"老铁""家人们""双击屏幕"（详见 series-context 第 7 节调性禁区）
❌ 不要省略 ACRCloud 复核（被投诉版权 = 整条限流）
❌ 不要让老磊"哭出声"（克制是这套调性的命脉，气音 ≤1 秒就够了）
❌ 不要在 D7 反转前的 D2-D5 暴露"夜里那个"的存在（保留悬念）
