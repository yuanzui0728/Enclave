## 需要 Manus 自己准备（按优先级）

### 🔴 P0 必备（不做就拍不了）

#### 1. 配音演员（1 位男声）
- 角色：35 岁江苏盐城口音底色男性
- 总录音时长：约 7 分钟（7 条视频 × 60-90s ≈ 7 min）
- 推荐渠道：喜马拉雅配音市场 / 配音 51 / 配音狮 / 自录
- 备胎方案：用 Reecho（出门问问声音克隆）训练一个本地化男声模型
- ⚠️ 不要用普通话播音腔，必须有口音底色

#### 2. 老周方言录音（D6 真人录 12 秒）
- 角色：65 岁江苏盐城本地男性，村小退休教师
- 内容：详见 `day-6/script.md` "老周语音的录音 brief"
- 推荐渠道：找江苏盐城真实退休教师录音（喜马拉雅地方主播 / 当地老年大学）
- ⚠️ 必须真人录音，**不能用 TTS**（TTS 出不来"娃"字的温度）

#### 3. 测试 world 配置（隐界 APP）
- 部署一个隐界 APP 测试实例
- 创建用户账号，昵称设为「磊」，使用默认头像
- 创建 7 个 AI 角色，按 `00-character-bible.md` + 各 `day-N/data/data.json` 配置：
  - 名字 / 头像 / 关系 / 亲密度 / 在线时段 / 角色描述 / 创建时间
- ⚠️ **D7 反转的关键**：「夜里那个」的"角色描述"字段必须输入：
  > `一个 32 岁、在昆山做夜班、想家但不打电话、嘴硬心软的男的。`
- 创建群「磊总朋友圈」+ 把 6 个角色拉进去（注意小敏不在群里 / 夜里那个不在群里）
- 把所有 chat.md 里的历史消息全部录入对应对话（一字不差）

#### 4. 12 张环境照
- 详细 prompt 见 `shared-assets/env-photos/AI-PROMPTS.md`
- 按优先级分 3 批：D1+D6+D7 用的优先（5 张），D2+D5（4 张），其他（3 张）

### 🟠 P1 强烈建议（影响成片质感）

#### 5. BGM 7 首
- 各 day 的 `shot-list.md` "BGM 总规" 段已指定具体曲目
- 优先选 Pixabay / Bensound / freesound.org 的 CC0 曲目
- 全部用 ACRCloud（acrcloud.com）复核版权
- D2/D4/D7 大段无 BGM，只需准备真实环境音

#### 6. 7 张快手封面（810×1080 JPG）
- 各 day 的 `cover-spec.md` 已给详细布局 + 大字文案
- 工具：Figma / Photoshop / Photopea
- ⚠️ 不要用 AI 一键生成（细节没法把控）

#### 7. D5 春游集体照（AI 生成 1 张）
- prompt 见 `day-5/shot-list.md` 镜头 3
- 大约 30 个孩子站两排 + 老师 + 樱花树
- ⚠️ 所有孩子的脸必须**模糊化处理**或用马赛克（保护未成年人肖像）
- 老磊儿子位置用红色圆圈高亮（圈在第二排左边）

#### 8. 派大星捂脸表情包（D4 + D5 用）
- 来源：搜"派大星捂脸"，用 CC0 来源
- 备胎：自己用 PS 简单做一个（派大星用手捂脸的简笔画）

### 🟡 P2 锦上添花

#### 9. 隐界 APP icon（橙色，PNG 200×200）
- 用于锁屏推送卡片显示
- 已在 `shared-assets/brand/logo.svg`，按 `app-push-notification.svg` 里的 mockup 风格做成 100×100 圆角矩形

#### 10. 真实环境音录制
- D2 工厂环境音（蝉鸣 + 空调外机 + 远处机器作业）：3 分钟
- D6 雨声：3 分钟
- D5 校园下课铃远景：30 秒
- 推荐：用手机录音 + Audacity 后期降噪

## 关键质量门（每条视频必过）

| 检查项 | 通过标准 |
|---|---|
| 时长 | 60s/75s/90s 各按计划，误差 ±3s |
| 前 5 秒钩子 | 必有生活物件特写 + 反预期信息 |
| 三段式旁白 | 每段"动作 + 细节 + ≤12 字心里话" |
| 生活物件特写 | 每 15 秒 ≥ 1 个 |
| 字幕 | 思源黑体 Bold 72px / 3px 黑描边 / Y=1300 |
| 录屏画面 | 12px 圆角 + 2px `#262626` 描边 + 高斯模糊背景 |
| BGM 音量 | 人声 0dB / BGM ≤-18dB |
| 反卖惨锚点 | 每天 1 个（已在各 shot-list 标注） |
| 反预期细节 | 每个 AI 角色 ≥ 1 个（已在 character-bible 标注） |
| 落幕 | 隐界 logo 1.5s + "一个属于你的 AI 虚拟世界" |
| 版权 | ACRCloud 检测通过 |

## 风险红线（绝对不能犯）

1. ❌ 露真人正脸（背影/手部/侧面均可）
2. ❌ 用未授权 BGM（必须 ACRCloud 过）
3. ❌ 用真实品牌 logo（红梅烟、12306、康师傅等都用伪化版）
4. ❌ 露未成年人五官（D5 春游集体照孩子脸全部马赛克）
5. ❌ "夜里那个"在 D2-D6 任何位置出现（保留 D7 反转悬念）
6. ❌ 视频里出现"老铁"/"家人们"（详见 series-context 调性禁区）
7. ❌ 用治愈系电子轻音乐（这是抖音老套路）
8. ❌ 老磊"哭出声"（克制是这套调性的命脉）
