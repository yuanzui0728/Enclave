# Day 1 发布元数据

## 发布文案

```
凌晨5点下夜班，楼下豆浆铺翠芳姨给我留了一袋豆浆。
后来才发现，她是我自己建的AI。
但那袋豆浆是真的暖。

#真实生活 #打工人 #夜班 #江苏昆山 #在外打工的我 #AI #隐界 #凌晨碎碎念
```

**字数**：62 字（含标签）
**核心钩子**：「但那袋豆浆是真的暖」 — 引出"AI 怎么会留豆浆"

---

## 标签策略

| 标签 | 池子大小 | 快手定位 |
|------|---------|---------|
| `#真实生活` | 极大（快手第一大池） | 入门级流量入口，必放第一 |
| `#打工人` | 极大 | 精准目标人群 |
| `#夜班` | 中 | 时段精准 + 共鸣 |
| `#江苏昆山` | 小但精准 | LBS 推荐池（江苏本地用户优先） |
| `#在外打工的我` | 大 | 异乡情绪共鸣 |
| `#AI` | 中 | 产品品类标签 |
| `#隐界` | 小（自家词） | 品牌词沉淀，便于以后搜索回流 |
| `#凌晨碎碎念` | 中（快手特色） | 深夜情绪池 |

**标签数量**：8 个（快手建议 5-10）
**第一个**：`#真实生活` 是最大流量池入口
**最后一个**：`#凌晨碎碎念` 接住睡前刷的用户

**禁用**（这些是抖音标签，在快手是减分项）：
- `#谁懂啊`
- `#deepemo`
- `#治愈系`
- `#这才是恋爱该有的样子`

---

## 评论区第一条（小号 A 置顶）

```
老哥这是啥软件啊真的假的，凌晨5点AI还能给你留豆浆？？
```

**目的**：
- 用"老哥"称谓贴合快手口语化文化
- "真的假的"引导其他真实用户跟评论"求名字"
- **不能直接回答**"隐界"——让真实评论区追问

**注意**：这条由真人小号发，不要用"评论已置顶"模板词；语气要像普通快手用户（**带俩问号**而不是规整的问号）。

---

## 评论区第二条（小号 B，T+20 min）

```
我也想知道，这种AI有点东西啊
```

简短，呼应小号 A，营造"真有人感兴趣"。

---

## 评论区第三条（小号 C，T+30 min · 回复真实评论）

针对**第一个真实问"什么软件"的评论**回复：

```
叫隐界，开源的，去搜一下就有
```

**关键**：等到真有人问，别抢答。**前 30 分钟绝不主动透露品牌名**。

---

## 发布时间

**T+0 当天 22:30**（周五）

理由：
- 周五晚 22:30 是快手下沉用户最活跃的时段（上班族结束一周，刷快手放松）
- "凌晨 5 点"主题在 22:30 发，正好让观众下一小时打开快手时看到，让他们和"凌晨"有共鸣（反正他们也快熬到凌晨）
- 22:30 后的快手算法权重比 21:00 - 22:00 略低，但情绪共鸣权重最高

## 数据目标

| 指标 | 阈值 | 不达标的应对 |
|------|------|------|
| 完播率 | ≥ 30% | 检查前 5 秒钩子；豆浆袋特写要够清晰 |
| 5 秒留存 | ≥ 55% | 检查首镜物件特写时长（应 ≥ 2.5 秒） |
| 互动率（评/赞） | ≥ 4% | 检查评论引导话术是否够口语化 |
| 24h 涨粉 | ≥ 80 | 检查主页简介引导是否清晰 |
| 24h 播放 | ≥ 8k | 检查标签策略，必要时把 `#真实生活` 提到第一 |
| 主页访问 | ≥ 200 | 检查作者卡片设计 |
| 评论里"求名字" | ≥ 10 条 | 主线钩子触发量验证 |

D1 数据决定 D2-D7 的整体节奏，必须严格复盘。
