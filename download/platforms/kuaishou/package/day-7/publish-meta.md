# Day 7 发布元数据

## 发布文案

```
凌晨1点，我点开了那个我从来没注意过的AI。
点进角色编辑，看到了我自己写的那行字——
"32岁，在昆山做夜班，想家但不打电话，嘴硬心软的男的。"
原来不是AI在陪我，是白天的我，陪夜里的我。

#真实生活 #打工人 #成年人也哭 #隐界 #AI #反转 #自我和解 #在外打工的我
```

**字数**：120 字（含标签）
**核心钩子**：「原来不是 AI 在陪我，是白天的我，陪夜里的我」 — 反转的整句直接放在文案里（D7 是揭示日，不需要藏）

---

## 标签策略

| 标签 | 池子大小 | 快手定位 |
|------|---------|---------|
| `#真实生活` | 极大 | 入门级流量入口 |
| `#打工人` | 极大 | 精准人群 |
| `#成年人也哭` | 中 | 与 D6 联动的情感标签 |
| `#隐界` | 小（自家词） | D7 是揭示日，主推品牌词 |
| `#AI` | 中 | 产品品类 |
| `#反转` | 大 | 反转向流量池（D7 独有） |
| `#自我和解` | 中 | D7 的核心情感 |
| `#在外打工的我` | 大 | 异乡情绪 |

**标签数量**：8 个

**核心策略变化（与 D6 比）**：

- 加了 `#反转`——D7 是揭示日，必须吃反转流量池
- 加了 `#自我和解`——D7 的情感不是 D6 的"被治愈"，是"自己接纳自己"
- 砍掉了 `#苏北` `#江苏盐城` `#思乡`（D7 与方言/地域无关，是普世主题）
